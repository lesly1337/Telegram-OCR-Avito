# Telegram OCR Avito Agent 🤖🔍

Локальный Telegram-бот-агент для автономного сбора данных с Avito и OCR-обработки изображений. Проект использует локальную LLM (Ollama) для понимания естественного языка и извлекает структурированные данные (IMEI, SN, MAC, пароли) без использования облачных AI-API.

## 🎯 Цель проекта
Разработать автономного агента, который:
1. Принимает запрос на естественном языке (например, «найди 15 iphone 13, нужны sn и imei»).
2. Уточняет параметры (если нужно).
3. Парсит выдачу Avito и скачивает изображения.
4. Выполняет локальный OCR.
5. Извлекает целевые сущности (IMEI с валидацией по Луну, MAC-адреса, SN, пароли).
6. Формирует и отправляет пользователю XLSX-отчет.

**Ключевое требование:** Полная автономность, отсутствие внешних AI-API (OpenAI, Anthropic и т.д.), работа через Docker Compose.

---

## 🏗 Архитектура

- **Telegram UI:** `aiogram 3` (асинхронный, FSM).
- **NLU (Понимание запросов):** `LangChain` + `Ollama` (локальная модель `qwen2.5:7b-instruct`).
- **Парсинг Avito:** `Playwright` (обход защиты) + `curl_cffi` (скачивание картинок).
- **OCR:** `pytesseract` + `EasyOCR`.
- **Извлечение данных:** Регулярные выражения + проверка по алгоритму Луна.
- **База данных:** `SQLite` (`aiosqlite`) для кэша, задач и сущностей.
- **Отчеты:** `pandas` + `openpyxl`.
